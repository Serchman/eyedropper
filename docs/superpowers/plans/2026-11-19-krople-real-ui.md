# Krople Real UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn the `krople-test` Tauri prototype into the real Krople app: Rust-owned patient cards with the two drop protocols, the mockup's "oko z postępem" main window, hold-to-confirm buttons, settings view, X-hides and autostart-icon-only.

**Architecture:** Rust (`src-tauri/src/timers.rs`) owns the patient list and a pure state machine (functions taking `now` + durations, unit-tested); the 1 s ticker broadcasts a `state` event to both windows, as today. The main window (`src/`) only draws that state: pure view logic in `src/card.js` / `src/format.js` (unit-tested with `node --test`), DOM in `src/main.js`, press-and-hold in `src/hold.js`.

**Tech Stack:** Tauri 2 (Rust), plugins store/autostart/single-instance/window-state; vanilla HTML/CSS/ES modules; `node --test` (Node 20) for pure JS.

**Spec:** `docs/superpowers/specs/2026-11-19-krople-real-ui-design.md` (read it; the card-state table there is binding). Domain notes: `docs/krople-real-app-notes.md`. Mockup markup, decoded and cleaned: `docs/mockup/oko-z-postepem.html` (`sc-camel-view-box` there means `viewBox`).

All paths below are relative to `krople-test/` unless they start with `docs/`.

## Global Constraints

- Polish UI copy, exactly: "Inicjały lub imię", placeholder "np. A.K.", "1 kropla", "3 krople co {interval} min", "Czeka", "Kropić teraz", "Gotowy do badania", "Zakropione", "Zbadany", "Brak pacjentów", "Ustawienia", "Wróć", "Odstęp między kroplami, min", "Czas oczekiwania, min", "Uruchamiaj z Windows", "Zakończ", "Minimalizuj", protocol labels "1 kropla" / "3 krople".
- A card is red when `phase_ends_at <= now`. Icon number = count of red cards; icon red while main window open too.
- Card order = arrival order; new cards appended at the end. No reordering.
- Card buttons ("Zakropione", "Zbadany", "×") are press-and-hold, 1500 ms, visible left→right fill; release / pointer leave / blur cancels and resets; Space/Enter held on a focused button works the same; fires once. A plain click does nothing.
- Label: trimmed, 1–20 characters (Unicode chars, not bytes). Settings: `intervalMinutes` default 10, range 1–60; `waitMinutes` default 15, range 1–120. Settings changes apply only to phases started after the change.
- Patient data lives only in Rust memory; never written to disk, never logged.
- Render with DOM calls + `textContent`, never `innerHTML`. CSP stays `default-src 'self'; connect-src ipc: http://ipc.localhost` — no remote fonts/scripts.
- Overdue time "+N min" (whole minutes, floor, from "+0 min"); running time "m:ss".
- Colours: `#111418` ink, `#C62828` red border/pie, `#B3261E` red text/button, `#FDECEC` red card bg, `#F4F6F9` card bg, `#DCE1E7` card border, `#C3C9D1` grey button border, `#4A515B` muted, `#5A3A3A` protocol label on red card.
- Main-window X / Alt+F4 hides, never quits; "Zakończ" (settings) is the only quit.
- Product name / identifier / installer name unchanged.

## Review Focus

1. Names with Polish diacritics or exactly 20/21 chars, or whitespace-only — must be counted in chars and rejected/accepted consistently in Rust and the input (`maxlength="20"`). (Task 1 test `label_validation`.)
2. A button being held while the 1 s `state` tick arrives — the hold must not reset (keyed render keeps the same button element). (Task 4 manual check; Task 3 keyed render.)
3. `mark_drop` on a 1-kropla patient, on a 3-krople patient that already has 3 drops, or on an unknown id — must return `Err` and leave state unchanged (no 4th drop from a double-fire). (Task 1 test `mark_drop_rejects`.)
4. Changing the interval/wait while cards are running — existing `phase_ends_at` must not move. (Task 1 test `durations_are_captured_at_phase_start`.)
5. Clock jumps (sleep, clock set back) — progress fraction must clamp to 0..1, never negative or >1, and a phase that ended during sleep is red on the next tick. (Task 3 test `fraction clamps`; Task 1 test `is_red_boundary`.)

- Permissions: main = event listen/unlisten, `core:window:allow-minimize`, `allow-get-state`, `allow-add-patient`, `allow-mark-drop`, `allow-remove-patient`, `allow-quit-app`, `allow-get-settings`, `allow-set-interval-minutes`, `allow-set-wait-minutes`, `allow-set-autostart`. Icon = event listen/unlisten, `core:window:allow-start-dragging`, `allow-get-state`, `allow-show-main`.
